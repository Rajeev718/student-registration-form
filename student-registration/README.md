# Student Registration Form

## Run karne ke steps
1. `npm install`
2. `npm start`
3. Browser me kholein: http://localhost:3000

## Folder structure
- server.js        -> Express backend (API + data save)
- public/          -> Frontend (index.html, style.css, script.js)
- students.json    -> Registered students ka data (auto-create hota hai)
